# Contributing to Awesome AI Bots

Thanks for helping keep this list awesome! 🎉

## How to add a bot

1. **Fork** the repo and create a branch: `git checkout -b add/bot-name`
2. **Add the bot** to the relevant table in `README.md`, in alphabetical order.
3. **Commit**: `git commit -m "Add BotName"`
4. **Push & PR**: push to your fork, then open a pull request.

## Entry format

Each row uses this format:

```
| [Bot Name](https://link-to-bot) | Type | ✅/❌ | Brief one-line description. |
```

- **Type**: pick one — *Autonomous Agent · Coding Assistant · Research · Creative · Productivity · Framework · Chatbot*
- **Open Source**: `✅` if the source is publicly available, `❌` otherwise
- **Description**: concise, factual, and neutral (max ~120 chars)

## Guidelines

- Link to the bot's official site, documentation, or source repository.
- Avoid marketing fluff — describe what the bot actually does.
- Do not add bots that are purely LLM wrappers without distinct agentic behavior.
- Keep tables in alphabetical order within each section.
- One bot per PR is preferred, but related additions are fine.

## Code of Conduct

Be respectful, factual, and constructive. The maintainers reserve the right to
close PRs that don't meet these standards.
